# NSMBW Red Mushroom House Solver

![image](screenshot.png)

A small web tool that helps you solve the **Red Toad House "Power-up Panels"** puzzle in
*New Super Mario Bros. Wii*.

## Combinations

All possible combinations are listed [here](html/info.html).

## Supported worlds

Worlds 1 through 9.
